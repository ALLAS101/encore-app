# Encore

Live party quizzes and *Name That Tune* music rounds. Host on a big screen, play on your phone.

**Play now:** https://playencore.web.app — no account needed.

## Android app

[**⬇ Download Encore.apk**](https://github.com/ALLAS101/encore-app/releases/latest/download/Encore.apk) (Android 7.0 or newer, 64-bit)

1. Open `Encore.apk` when the download finishes.
2. If Android asks, allow your browser to install apps.
3. Tap **Install**.

All versions are on the [Releases](https://github.com/ALLAS101/encore-app/releases) page.

## iPhone, iPad and computers

Open https://playencore.web.app and use **Get the app** on the title screen:
- **iPhone / iPad:** Safari → Share → *Add to Home Screen*.
- **Computer:** Chrome or Edge → the install icon in the address bar.
